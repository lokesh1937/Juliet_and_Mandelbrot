# Juliet_and_Mandelbrot
The function 𝑓(𝑧)=𝑧2+𝑐
f(z)=z2+c is famous for creating fractal shapes in complex dynamics and fractal geometry.

1.A Julia set is formed by fixing a constant value of 𝑐 and iterating
           𝑧𝑛+1=𝑧𝑛^2+𝑐

for different starting values of 𝑧.
Each different value of 𝑐 produces a different shape.

2.Mandelbrot Set
The Mandelbrot set is the set of all values of 𝑐 for which the sequence
            zn+1=zn^2+c,z0=0
    Each point c in mandelbrot set correspons to one juliet set.
