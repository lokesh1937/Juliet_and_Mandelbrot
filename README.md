# Juliet_and_Mandelbrot
The function
#### f(z)=z2+c is famous for creating fractal shapes in complex dynamics and fractal geometry.

### Julia Set
A Julia set is formed by fixing a constant value of 𝑐 and iterating <br>
         >>  𝑧𝑛+1=𝑧𝑛^2+𝑐 <br>

for different starting values of 𝑧.<br>
Each different value of 𝑐 produces a different shape.

### Mandelbrot sets
The Mandelbrot set is the set of all values of 𝑐 for which the sequence <br>
           >> zn+1=zn^2+c,z0=0 <br>
    Each point c in mandelbrot set correspons to one juliet set.
